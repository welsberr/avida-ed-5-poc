Projektfortschritt aktualisieren

Dies ist eine gemeinsam genutzte, versionskontrollierte Aufzeichnung. Aktualisieren Sie das Meilenstein in progress.json auf GitHub oder in einer lokalen Checkout, fügen Sie einen datierten Fortschritts-Eintrag hinzu und beinhalten Sie öffentliche Beweise wie einen Commit, Testbericht oder Review. Schreibzugriff auf das Repository oder ein Pull Request ist erforderlich.

Führen Sie python3 scripts/render_roadmap.py aus, committen Sie die Daten und die generierte Seite, und pushen Sie. GitHub Seiten rebuilden diese Ansicht aus der Aufzeichnung. Validierung lehnt inkonsistente Statusgeschichte und Abschluss ohne akzeptierte Kriterien und Beweise ab. Lesen Sie die Aktualisierungsanweisungen.

Keine browser-lokalen Checkboxen oder Besucher-Übermittlungen ändern die gemeinsame Projekt-Aufzeichnung. Die Quellgeschichte bewahrt, wer es geändert hat und warum.
